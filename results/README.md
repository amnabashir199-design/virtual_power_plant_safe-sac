# Results Directory

- `authoritative/`: publication-freeze and evidence documents plus explicitly labeled unmodified source tables used to audit the daily-average DR convention.
- `baseline/`: corrected deterministic daily metrics and independent baseline reproduction evidence.
- `scenarios/`: detailed deterministic scenario metrics, affected low-IT repair evidence, and IT-analysis summaries.
- `ablations/`: detailed independently trained ablation metrics and integrity check.
- `reproduced/`: generated by the reproduction commands; never treated as an authoritative input.
- `REPRODUCTION_VALIDATION.csv`: published/final versus reproduced values, differences, tolerances, and pass status.

The authoritative manuscript tables are stored once under `../tables/` to avoid duplicate copies.
